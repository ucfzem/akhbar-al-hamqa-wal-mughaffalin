# أخبار الحمقى والمغفلين — ابن الجوزي

قارئ رقمي كامل لكتاب **«أخبار الحمقى والمغفلين»** لأبي الفرج عبد الرحمن بن علي **ابن الجوزي** (المتوفى 597 هـ)، يعمل **دون إنترنت** بعد أول زيارة، بواجهة عربية (RTL) مستوحاة من طراز الكتب الورقية (رَقّ/ذهبي/أخضر).

## الرابط

- التطبيق: https://ucfzem.github.io/akhbar-al-hamqa-wal-mughaffalin/
- المكتبة (works): https://ucfzem.github.io/works/

## المزايا

- **الفهرس التفاعلي**: أربعة وعشرون باباً (بطاقة الكتاب + مقدمة الكتاب + الأبواب) مع فلاتر وعدّاد نتائج لكل باب.
- **بحث فوري** مع:
  - عدّاد إجمالي («نتائج البحث عن «…»: N»),
  - **تظليل الكلمات** في العنوان والسند والنص،
  - تحمّل الاختلافات في التشكيل والهمزات (أ إ آ ٱ → ا، ى → ي، ة → ه، ؤ ئ → و).
- **تنقّل بين نتائج البحث** داخل الباب وعبره (السابق/التالي + اختصارات).
- **لائحة الأبواب** الجانبية + طيّها على الجوال.
- **المظهر**: فاتح/داكن، وتحكّم بحجم الخط.
- **نسخ الباب** ومشاركته، وحفظ موضع القراءة.
- **اختصارات لوحة المفاتيح**: `/` للبحث، الأسهم للتنقّل بين الأبواب، `Enter`/`Shift+Enter` بين النتائج، `Esc` للمسح.
- **عمل كامل دون إنترنت** (Service Worker) + إمكانية التثبيت (PWA).

## البنية

```
.
├── index.html          واجهة القارئ
├── style.css           الأنماط (فاتح/داكن)
├── app.js              المنطق (الفهرس، البحث، التنقّل، المظهر…)
├── sw.js               Service Worker (تخزين الهيكل والبيانات والخطوط)
├── manifest.json       بيانات تطبيق الويب (PWA)
├── data/
│   └── chapters.json   نص الكتاب: { meta, chapters:[{ id, title, content:[…] }] }
├── icon.svg            الأيقونة (قبّعة مهرّج بثلاث شارات)
├── icon-192.png
├── icon-512.png
└── tools/
    └── render_icons.mjs  توليد أيقونات PNG من SVG (Playwright)
```

## المصدر
